# BirdCall-NeuralNetwork

-	Built multiple ML and neural‑network models to classify bird species from short bird-call audio clips.
-	Used Jupyter Notebook to create and compare Keras, PyTorch, and KNN models, tuning with Optuna.

---

## Files 📁
-- **dataset.csv**: bird call dataset we used from Cornell Lab's *Birdsong Recognition Competition*
-- **Bird_Call_Report_Final.ipynb**: ML and Neural Network code in a Jupyter file
-- **BirdCallReportFinal.pdf**: PDF version of Jupyter Notebook code with additional insights
-- **DASC 400 Bird Call Project.pptx**: Presentation of our work, findings, and conclusions
